# Release Notes: v0.7.0

**Release Date:** 2026-10-27

## Highlights

- `Session.Hangup` ends the call, not just the media stream

## What's New

### Hanging Up Calls

`Session.Hangup(ctx)` sends the Call Control hangup command and then closes the session. `Close` stops only the session's media stream, which leaves a Telnyx call connected without audio.

```go
sess, err := gw.MakeCallWithOptions(ctx, "+16695550100",
    corecallsystem.WithSendDigits("WWWW85012345678#WWWWWWWW*482913#"),
)
if err != nil {
    return err
}

// Later, to leave:
if err := sess.(interface{ Hangup(context.Context) error }).Hangup(ctx); err != nil {
    return err
}
```

Sessions in every pipeline mode have `Hangup`, including audio-mode sessions. OmniMeet's dial-in joiner calls it when an agent leaves a meeting, so the agent no longer stays on the line.

## Migration Guide

### From v0.6.0

No code changes are required. Code that ends calls by closing the session should call `Hangup` instead, since `Close` leaves the call connected.
