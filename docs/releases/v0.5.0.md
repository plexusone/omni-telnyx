# Release Notes: v0.5.0

**Release Date:** 2026-10-27

## Highlights

- Send keypad digits (DTMF) once an outbound call is answered, for example to join a meeting's phone dial-in line
- Pass omnivoice-core call options through the gateway with `MakeCallWithOptions`
- Fix the gateway treating its own outbound calls as incoming calls

## What's New

### Keypad Digits on Outbound Calls

`MakeCall` now honors omnivoice-core's `callsystem.WithSendDigits`. The digits are held on the call and sent with Telnyx's `send_dtmf` command when the call is answered.

```go
import corecallsystem "github.com/plexusone/omnivoice-core/callsystem"

// Wait 4 seconds, enter the meeting ID and #, wait 8 seconds, then enter
// * and the passcode and #.
call, err := provider.MakeCall(ctx, "+16695550100",
    corecallsystem.WithSendDigits("WWWW85012345678#WWWWWWWW*482913#"),
)
```

Digits use dial-string notation: `0`-`9`, `*`, `#`, and `A`-`D` are tones, `w` waits half a second, and `W` waits one second. Invalid digits return an error before the call is placed.

The voice gateway sends the digits on the `call.answered` webhook, before starting media streaming. Without the gateway, call `SendPendingDigits` on the `*callsystem.Call` when you receive `call.answered`. The digits are sent once per call, with a command ID so that a retried webhook cannot enter them twice.

### Gateway Call Options

The voice gateway implements omnivoice-core's `gateway.OptionCaller`. `MakeCallWithOptions(ctx, to, opts...)` passes call options to the call system, and provider-neutral code can use `gateway.MakeCallWithOptions(ctx, gw, to, opts...)` from omnivoice-core. `MakeCall(ctx, to)` is unchanged.

## Bug Fixes

### Outbound `call.initiated`

Telnyx sends `call.initiated` for calls placed with `MakeCall` as well as for incoming calls. The gateway treated every `call.initiated` as a new incoming call: it ran the incoming call handler, registered the call again as inbound, and tried to answer it. The gateway now ignores `call.initiated` for outgoing calls, which `MakeCall` already registered.

## Testing

- Unit tests against a local fake of the Telnyx API: digits wait for the answer and are sent once with a command ID, calls without digits send nothing, and invalid digits place no call
- Unit test that an outgoing `call.initiated` does not reach the incoming call handler or create a session

## Migration Guide

### From v0.4.0

No code changes are required. Applications that handled outbound `call.initiated` events by relying on the gateway's incoming call handler no longer see them there.
